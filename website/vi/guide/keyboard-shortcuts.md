# Phím tắt

Tài liệu tham khảo đầy đủ về các phím tắt có sẵn trong NavSlides Editor.

## Phím tắt chỉnh sửa

| Phím tắt | Hành động |
|---|---|
| `Ctrl+Z` | Hoàn tác |
| `Ctrl+Y` / `Ctrl+Shift+Z` | Làm lại |
| `Ctrl+C` | Sao chép (các) phần tử đang chọn |
| `Ctrl+X` | Cắt (các) phần tử đang chọn |
| `Ctrl+V` | Dán (các) phần tử |
| `Ctrl+D` | Nhân bản (các) phần tử đang chọn |
| `Ctrl+F` | Tìm & thay thế |
| `Delete` / `Backspace` | Xóa (các) phần tử đang chọn |
| `Escape` | Bỏ chọn phần tử / dừng chỉnh sửa văn bản / đóng bảng |

## Định vị & đổi kích thước

| Phím tắt | Hành động |
|---|---|
| `Arrow keys` | Dịch phần tử đang chọn 1 px |
| `Shift+Arrow keys` | Dịch phần tử đang chọn 10 px |
| `Shift+drag` | Giữ nguyên tỷ lệ khung hình khi đổi kích thước |
| `Shift+rotate` | Bắt góc xoay theo bước 15° |

## Chế độ trình chiếu

| Phím tắt | Hành động |
|---|---|
| `F5` | Bắt đầu trình chiếu từ slide đầu tiên |
| `Shift+F5` | Bắt đầu trình chiếu từ slide hiện tại |
| `←` / `→` | Slide trước / slide kế |
| `↑` / `↓` | Điều hướng trong các chồng slide dọc |
| `Escape` | Thoát chế độ trình chiếu |
| `S` | Mở cửa sổ ghi chú người trình bày |
| `B` | Tạm dừng / làm tối màn hình |
| `?` | Hiển thị lớp trợ giúp phím tắt của reveal.js |

## Chỉnh sửa văn bản (bên trong một phần tử văn bản)

| Phím tắt | Hành động |
|---|---|
| `Ctrl+B` | In đậm |
| `Ctrl+I` | In nghiêng |
| `Ctrl+U` | Gạch chân |
| `Ctrl+Shift+X` | Gạch ngang |
| `Ctrl+Shift+H` | Tô sáng |
| `Ctrl+A` | Chọn toàn bộ văn bản trong phần tử |
| `Ctrl+Z` / `Ctrl+Y` | Hoàn tác / làm lại trong văn bản |

::: tip
Nhấn `Escape` một lần để kết thúc chỉnh sửa văn bản mà vẫn giữ phần tử được chọn. Nhấn `Escape` lần nữa để bỏ chọn hoàn toàn.
:::
