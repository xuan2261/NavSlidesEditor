1. The Core Problem: NavSlides Editor is a self-hostable WYSIWYG presentation editor — no account, no telemetry, no subscription. Built as a 4-package monorepo with 510 unit tests, 127 E2E tests, PPTX import at 97% fidelity, Socket.IO live rooms, and 7 gamified classroom games. Development required a multi-agent workflow. 2. Core Logic Flow: Research → Planning → Implementation → Testing → Review → Docs. Research runs multiple agents in parallel benchmarking PPTX parsers on 145 slides, exploring geometry math, surveying SVG sanitization. Planner synthesizes findings into phased plans with file ownership. Implementation runs in parallel reducing SlideCanvas from 2,759 to 841 LOC, building the PPTX geometry layer, wiring Socket.IO timer events. Tester runs Vitest + Playwright + ESLint looping fixes until all pass. Reviewer checks correctness and security, docs manager syncs architecture. 3. AI-Backed Features: AI Copywriting generates slide content from a topic via a custom endpoint with SSRF guards and Zod validation. AI Translation translates presentations into 20+ languages.
