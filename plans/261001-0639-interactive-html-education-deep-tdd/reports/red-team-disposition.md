## Whole-plan reconciliation

The root execution contract now states per-capability authority, effective tuple mapping, preservation of +10 buzz policy, admission/media ownership and package-before-final-gate order. Phase03's old instruction assigning existing grading cutover only to12 was removed; later phase prose no longer instructs reusing a prerequisite runtime bundle. Phase14's new admission/media/peer duties appear in inventories, implementation steps, focused commands and acceptance.

The focused command lists include the new canonical-live, variable-admission and nested-media tests. PowerShell release commands use separate invocations instead of PowerShell7-only `&&`; execute one command at a time and stop on nonzero status. Baseline01 explicitly selects current-source dev servers as well.

No feature was removed. Canonical19, final game19, all seven question kinds, six existing simulations and all26 scope-ledger outcomes remain required. Runtime claims remain unverified until their phase-specific browser/server/file/package gates run.
