  🔴 BUG nghiêm trọng (sửa trước)

  B1. Token Tailwind không tồn tại — Active tab có thể render sai
  tab-bar-with-scroll-and-icons.jsx:25 dùng bg-background cho active tab và
  focus-visible:ring-ring cho focus ring. tailwind.config.js không định nghĩa
  background hay ring colors (chỉ có workspace, panel, card, secondary...).
  Class fail silent → active state mất hoặc fallback sai trong cả light/dark
  mode.
  ribbon-panel.jsx:27 cũng dùng bg-background cho container ribbon → cùng vấn
  đề.
  Fix: đổi sang bg-panel (active) hoặc thêm token background vào config; ring
  đổi ring-focus.

  B2. "Preview" button không có handler (Transitions + Animations)
  transitions-tab-content.jsx:177 và
  ribbon-element-animation-effect-controls-tab-content.jsx:110 đều có:
  onMouseDown={(e) => { e.preventDefault() }}
  Click vào → không gì xảy ra. User cảm thấy app bị bug. Hoặc wire onPreview,
  hoặc xoá button cho đến khi có chức năng.

  B3. onMouseDown + preventDefault thay cho onClick trên hầu hết buttons
  Pattern này được dùng để giữ TipTap text selection, nhưng được copy-paste khắp
   ribbon (kể cả những nơi không liên quan TipTap như Insert, Design, View). Hệ
  quả:
  - Touch events trên một số browser bị bỏ qua
  - Screen reader virtual cursor không activate
  - Không hỗ trợ keyboard mặc định (phải tự thêm onKeyDown)

  Fix: chỉ giữ pattern này ở text-formatting buttons (Bold, Italic,
  setColor...). Các nút khác dùng onClick.

  B4. bg-primary-light text-accent cho active state — không nhất quán giữa
  light/dark
  --color-primary-light: rgba(201, 100, 66, 0.16) là dark-mode-tuned. Trong
  light mode, nền cam nhạt 16% trên --bg-secondary: #fffaf2 rất mờ, khó nhận
  biết "đang active". Test contrast:
  - Dark: pressed indicator ~OK
  - Light: ~1.6:1 — fail WCAG 3:1 cho non-text UI element.

  🟠 Vấn đề Layout & Hierarchy (Header Bar)

  H1. Header gộp 6 vùng chức năng vào 1 dòng 44px (EditorPage.jsx:1211-1349)
  [Back] [TEMPLATE] [Title input] [Save|Undo|Redo] [File] [7 Tabs] [AI▾]
  [Share▾] [Present]
  - Trên màn hình <1280px, các label ẩn (hidden md:inline, hidden lg:inline,
  hidden xl:inline) → người dùng chỉ thấy icon, không phân biệt chức năng. Vi
  phạm nav-label-icon của Material.
  - Title input cố định 150–200px, không grow → tên dài bị truncate nhưng không
  có tooltip full text.
  - "Present" — đây là primary CTA của editor, nhưng dùng variant="icon" (xám,
  kích thước như mọi icon khác). Vi phạm primary-action (Apple HIG): mỗi screen
  chỉ 1 primary CTA và phải nổi bật.

  Fix kiến trúc: chia thành 2 hàng (giống PowerPoint/Keynote):
  Row 1 (40px): Back · TEMPLATE · Title · ········ Save status · AI▾ · Share▾ ·
  [PRESENT▶]
  Row 2 (32px): [File][Home Insert Design Format Transitions Animations View]
  Row 3 (80px): Tab content
  Hoặc giữ 1 row nhưng dùng variant="primary" cho Present và đặt nó ngoài cùng
  phải, kích thước w-auto px-3.

  H2. Inconsistent button heights trong cùng header
  - RibbonActionDropdown: h-8
  - FileDropdown: h-7 px-2
  - Present: variant="icon" = w-8 h-8
  - QuickAccessToolbar icons: h-7 w-7

  → Mắt thấy "lệch tầng". Chuẩn hoá: tất cả button ribbon header dùng cùng 1
  height (gợi ý: 32px = h-8).

  H3. File dropdown nằm SAU QuickAccessToolbar nhưng TRƯỚC tab bar
  File menu là "global commands" (Open/Export/Publish), tab bar là "per-slide
  tools". Đặt cạnh nhau khiến user không phân biệt nhóm. PowerPoint giải quyết
  bằng "File" tab riêng; Keynote bằng menu bar. Đề xuất: đặt File làm tab đầu
  tiên (như Office), hoặc gộp vào menu hamburger góc trái.

  R1. Tab strip (44px) + Ribbon panel (80px) = 124px chiều cao — chiếm ~12% màn
  hình 1080p chỉ cho navigation. Compare PowerPoint: ~96px. Đề xuất giảm tab

  R2. Tabs.Trigger redundant aria-label
  aria-label={tab.label}
  ...
  <Icon size={14} />
  <span className="hidden sm:inline">{tab.label}</span>
  Khi label hiển thị, screen reader đọc "Home, Home" 2 lần. Bỏ aria-label khi
  <span> hiển thị, hoặc luôn ẩn span và dựa vào aria-label.

  R3. Active tab indicator phụ thuộc vào background change — nếu B1 chưa fix,
  active state vô hình. Sau khi fix B1, vẫn nên thêm border-bottom dày 2-3px màu
   --brand để indicator rõ hơn (Material spec: 3px indicator).

  R4. overflow-x-auto ở cả RibbonPanel outer và mỗi tab inner → 2 scrollbar lồng
   nhau khi width hẹp, UX rối.

  R5. Ctrl+Alt+R toggle ribbon — không hiển thị shortcut này ở đâu (không
  tooltip, không status bar). User không biết feature tồn tại.

  🟡 Cross-cutting issues

  C1. Touch target failure tổng quát
  - Hầu hết button ribbon: h-7 w-7 = 28×28px. Apple HIG: 44pt. Material: 48dp.
  Fail trên touch devices (project quảng cáo support tablet/trackpad).
  - Inputs h-7 = 28px. Material yêu cầu 56dp cho input mobile.
  - Fix: thêm hitSlop thông qua padding của parent, hoặc media query @media
  (pointer: coarse) tăng size lên 36-40px.

  C2. Font sizes vi phạm readable-font-size
  - text-[10px] (section labels, captions): quá nhỏ
  - text-[11px] (button labels, dropdown items): biên giới WCAG
  - Tiêu chuẩn: 12px tối thiểu cho UI label, 14px cho body, 16px cho input
  mobile (tránh iOS auto-zoom).

  C3. Contrast --text-muted trên --surface-1
  - Dark: #8c7e72 trên #1b1714 ≈ 4.1:1 — fail AA cho normal text (cần 4.5:1)
  - Áp dụng nhiều: section labels, helper text, ChevronDown opacity-60.
  - Fix: dark --text-muted → #a39487 (~5.0:1).

  C4. 4 implementations dropdown khác nhau (DRY violation):
  - RibbonActionDropdown (header)
  - FileDropdown
  - RibbonDropdownMenuGroup (dùng useRef + Escape)
  - ParagraphCompactControls (inline implementation)
  → UX khác nhau (1 số có Escape, 1 số không; 1 số có outside click via fixed
  overlay, 1 số dùng addEventListener). Nên dùng @radix-ui/react-dropdown-menu
  (đã có Radix Tabs).

  C5. z-index magic numbers: 200, 999, 1000, 1100, 1000, 9999, 10000, 99999,
  100000 trong codebase.
  - Tokens chỉ có --z-modal và --z-modal-overlay.
  - Fix: thêm --z-header: 200, --z-dropdown: 1000, --z-popover: 1100, --z-toast:
   1500.

  C6. Reduced-motion ✓ — đã implement đúng ở index.css:208. Không cần fix.

  C7. Light mode chưa được test parity
  - border: rgba(244, 238, 231, 0.08) hardcoded cho dark; light đè lên rgba(58,
  45, 35, 0.12) — opacity 0.12 trên #fffaf2 ≈ vô hình. → Border light mode rất
  mờ, hierarchy thấp.

  C8. Title input feedback (EditorPage.jsx:1225)
  - Không có visual indicator khi auto-saving ngay tại input
  - Save status nằm cách title 200-300px (trong QuickAccessToolbar) — eye-travel
   dài, dễ miss "Save failed".
