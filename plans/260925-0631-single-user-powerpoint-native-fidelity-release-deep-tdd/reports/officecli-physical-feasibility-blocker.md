- The matching local executable's creation time was not independent acquisition evidence. The failed 2026-09-25 run used this metadata as `acquiredAt` but produced no receipt. The later external receipt still needs acquisition-provenance review before promotion.

The Phase 1 stop rule applied on 2026-09-25. Do not treat that failed run or unit-test doubles as physical evidence.
