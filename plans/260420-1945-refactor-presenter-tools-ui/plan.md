# Refactor Presenter Tools UI

## Overview

This plan aims to refactor the Presenter Tools UI and the Fullscreen button to minimize distraction during presentations. The tools (including Slide Menu, Custom Controls, and native Reveal navigation arrows) will become translucent (15% opacity) by default and fully visible (100% opacity) on hover. The Fullscreen button will also be simplified to just an icon and grouped with the other top-right tools in the Presenter Toolbar.
