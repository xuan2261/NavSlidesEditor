# Interactive Product Tour with react-joyride

## Overview

Nâng cấp hệ thống hướng dẫn người dùng (Onboarding/Tutorial) từ dạng Modal tĩnh sang hệ thống Product Tour tương tác trực tiếp bằng thư viện `react-joyride`. Hệ thống mới sẽ "đục lỗ" (highlight) các vùng UI quan trọng (Toolbar, Canvas, Properties Panel) và hiển thị tooltip giải thích ngay cạnh phần tử đó, giúp người dùng mới dễ dàng làm quen với giao diện NavSlidesEditor.
