## Export Warning Contract

Structured PPTX warnings now include:

- `elementId`
- `elementType`
- `control`
- `surface`
- `matrixRowId`
- `severity`
- `message`
- `fallback`

The report is attached as non-enumerable `warnings.exportReport`, so existing
string-array consumers continue to work. The editor export action keeps the
warnings user-visible through the browser export-result modal (`alert`) and
stores the latest report on `globalThis.__NAVSLIDES_LAST_PPTX_EXPORT_REPORT__`
for machine-readable inspection.
